您可在首次打开应用时的授权提示中阅读本政策，也可在“我的 → 隐私政策”直接阅读同一份正文。隐私问题和个人信息权利请求可通过第九节的邮箱提出。

一、我们收集信息的原则及目的

我们按功能所需的最小范围处理信息。应用提供二维码和条形码识别、制码、码册管理与本地工具，无需注册。扫码、制码和码册均在设备上运行。本安装包仅声明相机权限，无互联网访问权限，未集成广告或统计 SDK。

二、我们如何收集和使用您的个人信息

• 相机扫码。仅当您主动打开“扫一扫”或“连续扫码”时，应用才请求相机权限。允许后，相机画面用于在本机识别二维码与条形码，不保存预览画面。离开扫码页或应用进入后台后关闭相机。拒绝权限后，仍可手动识别、制码和使用码册。
• 识别、生成和保存。扫码结果及您主动输入的文字、网址、电话号码、名片、挪车信息、Wi-Fi 名称或密码，可按您的操作在本机解析或生成码图。标题、备注、收藏及保存的码值存入本地码册。您可在“我的”关闭单次识别自动保存，连续扫码可在完成时统一保存。Wi-Fi 工具只解析码内信息，不读取系统保存的密码，也不会自动连接网络。
• 复制和粘贴。应用响应您主动执行的操作，将选定内容复制到系统剪贴板，或使用您主动粘贴的内容。系统剪贴板由设备管理。
• 导入和导出。通过系统文件选择器读取您选中的备份或向您选择的位置写入文件。导出的 JSON、CSV、PNG 和 PDF 可能包含您保存的内容，文件在应用外由您自行管理。
• 反馈。点击“导出反馈文件”会在本机生成文件，其中含您填写的问题、应用版本和 Android API 版本。您可以自行决定是否将文件或其他信息发送给运营者。运营者收到反馈后，使用您主动提供的问题描述及必要的联系信息处理请求。

三、我们如何使用 Cookie 和同类技术

应用在设备上保存您的隐私授权选择、使用设置和本地记录。应用内没有通过 Cookie 或同类技术开展统计和广告追踪。您主动在浏览器打开本政策的公开查阅地址或其他网页链接时，网页托管服务和浏览器按各自的规则处理访问。

四、我们如何共享、转让、公开披露您的个人信息

应用内处理的扫码记录和码册在本机保存。经您确认打开网址，或主动选择分享时，选定的链接、文本或码图会交给您选择的浏览器、系统服务或其他应用。接收方按自己的规则处理所收到的内容。请在操作前核对接收方和资料，尤其是带有联系方式、Wi-Fi 密码的码图和备份。

运营者没有设置从本安装包自动上传、转让或公开披露码册内容的功能。对于您主动发送给运营者的信息，我们在办理请求所需范围内处理。依法需要向有关机关提供信息时，按法定条件和必要范围办理。

五、我们如何保存与保护您的个人信息

码册保存在应用私有空间，采用 AES-GCM 加密，密钥由 Android Keystore 管理。应用关闭系统自动备份。可在“我的”启用本地隐私锁。已保存的码册记录留存至您删除、清除应用数据或卸载。您已自行保存或分享的副本由您或接收方管理。

运营者对您通过邮箱提供的反馈及权利申请信息，仅在办理请求和依法留存所需期间保存。达到法定删除条件时依法删除或作匿名化处理。发生个人信息安全事件时，采取相应的补救措施，并依法履行告知和报告义务。

六、您对个人信息享有的权利

• 查阅、复制及更正。在“码册”打开记录可查阅、复制码值及编辑标题或备注。码值需要更正时，可以重新识别或生成并删除旧记录。可通过“我的 → 备份与导出”取得一份副本。
• 删除。在“码册”可删除单条记录，在“我的”可清除全部本地记录。清除应用数据或卸载也会清除应用内记录。导出的文件需要在其保存位置另行删除。
• 撤回同意。在手机系统的应用权限设置中可撤回相机权限。需要重新选择是否同意隐私政策时，可先备份需要保留的记录，再在系统设置中清除本应用数据。清除数据也会移除码册和设置，重新打开时会重新询问。撤回同意不影响此前依法进行的处理。
• 如需向运营者申请查阅、复制、更正、补充或删除已发送给我们的信息，撤回同意，或提出投诉，可通过第九节所列邮箱联系。本版本无需注册账号。

七、我们如何处理未成年人个人信息

未成年人请在父母或其他监护人指导下使用。涉及处理未满十四周岁儿童的个人信息，应依法先取得监护人同意。监护人可通过第九节的邮箱提出查阅、删除等请求。制作或分享二维码时请避免写入儿童姓名、住址、学校等可识别信息。

八、本政策如何更新

功能或个人信息处理规则发生变化时，我们会更新本政策并通过应用内提示等方式告知。处理目的、方式或信息种类发生变化且依法需要重新取得同意时，将重新征求您的同意。您可从“我的 → 隐私政策”查阅本版本的政策。
