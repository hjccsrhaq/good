本政策说明我们如何处理您在使用本应用时涉及的信息，以及您如何管理这些信息。请在使用前阅读本政策。

## 一、适用版本与基本说明

本应用提供“不接入SDK版”和“接入SuperCore版”，两种版本使用同一份隐私政策，扫码、制码与本地码册业务功能一致。

不接入SDK版不包含友盟统计、SuperCore及其广告、云控组件，不声明互联网访问权限，不通过本应用向服务器上传信息。接入SuperCore版集成友盟移动统计 U-App、SuperCore 2.0.6及其配套广告组件，会使用网络完成启动配置、广告请求、广告展示、效果统计与安全风控；相关处理仅适用于接入版。您可以选择不接入SDK版，继续使用扫码、制码及本地码册功能。

扫码、制码与本地码册无需注册账号。我们未在扫码业务中设置阅读奖励、悬浮窗、福利专区、实名认证或支付功能，也不以提供这些功能为由索取您的信息。

## 二、扫码与本地功能处理的信息

1. 相机识别：只有您主动选择扫码并同意系统相机授权后，应用才使用相机，在本机识别二维码或条形码。相机画面临时用于解码，不保存为照片或视频；离开扫码页面或应用进入后台后释放相机。拒绝相机权限仍可使用手动识别、生成码和本地工具。

2. 码值与记录：您扫描或填写的文本、链接、Wi-Fi名称和密码、名片、电话号码、挪车信息、标题、备注和收藏，在选择保存或开启自动保存时存入本地加密码册。扫码业务代码不将相机画面、码值正文、备注或Wi-Fi密码提交给友盟、SuperCore或广告组件。Wi-Fi工具仅解析码内信息，不读取系统已保存的密码、不自动连接网络。挪车码本身包含可被扫码者读取的联系信息，请谨慎分享。

3. 剪贴板：仅响应您主动复制或粘贴的操作，不在后台读取剪贴板。复制到系统剪贴板后的内容由操作系统管理，其他获准访问剪贴板的应用可能读取，请勿复制不必要的敏感信息。

4. 导入与导出：通过系统文件选择器读取您主动选择的备份文件，或写入您指定的PNG、CSV、JSON和反馈文件，不读取整个相册或文件目录。JSON、CSV备份是明文；二维码图片可被他人扫描读取。导出、分享前请核对内容和接收方。应用内隐私锁不保护已导出的文件。

5. 本地工具：单位换算、条码校验位、链接格式检查、文本比较和批量编码均在本机运行。链接格式检查不访问目标网站，不代表网站安全或商品真伪核验。

6. 反馈：App内“问题反馈”仅将您填写的问题及应用版本、Android API版本生成本地文件，不自动发送。若您主动向开发者提交反馈，我们会处理您提供的问题描述及为联系、解决问题所必要的信息，请避免提供密码、完整证件号码等无关内容。

## 三、接入SuperCore版的网络与第三方处理

本节只适用于接入SuperCore的安装包。不接入SDK版不运行本节组件，不因本节说明而增加信息收集。

SuperCore 2.0.6用于启动流程、应用渠道与配置获取，以及广告组件调度。其网络请求可能处理应用名称、包名、版本、渠道、设备及系统基本信息、网络状态、IP地址、设备标识和运行日志，以完成配置、安全校验及服务运行。

配套广告组件根据实际启用和展示场景，可能在本机获取并向其服务端传输下列信息，用于广告投放、展示和点击统计、效果评估、反作弊及故障诊断：设备品牌、型号、系统版本、屏幕分辨率和密度、语言、时区、CPU及存储等基础设备信息；Android ID、OAID或设备支持并可访问的广告标识；网络类型、运营商、网络连接及Wi-Fi状态、IP地址；应用包名、版本、渠道、前后台状态、相关应用安装或运行状态；广告展示、点击、转化记录及崩溃、性能和服务日志。互动广告还可能使用加速度、陀螺仪等传感器数据。具体字段受实际组件版本、系统限制、授权和组件配置约束；未展示某家广告不等于该组件必然完全不发生初始化或配置请求。

## 四、权限与外部操作

两种版本均按需申请相机权限，不为扫码业务申请定位、通讯录、麦克风、相册读取或电话状态权限。接入版增加互联网访问、网络及Wi-Fi状态、广告标识等组件所需权限或系统接口，并可能在系统支持时获知截屏、录屏状态，用于组件交互或风控；这些状态接口本身不授予采集屏幕图像的权限。网络状态、设备标识或IP地址等部分信息不通过系统运行时授权弹窗获取，不代表它们没有发生处理。

本次安装包不申请读取电话状态、精确或粗略定位、相册/外部存储读取、查询全部应用、安装其他应用或修改系统设置权限。接入版的广告组件还声明通知权限，用于其下载相关通知；在需要运行时授权的系统中，只有您同意系统授权后才能显示此类通知。扫码业务本身不主动请求通知授权，不提供消息推送服务。不接入SDK版不声明通知权限。导入导出通过系统文件选择器完成。系统限制可能影响部分广告组件的信息获取或扩展能力，不影响本地扫码和制码业务。

网址只在您确认后交由浏览器打开；分享和打印只在您主动操作后交给所选系统或第三方应用。浏览器、分享接收方、打印服务及您点击的广告目标页面可能按其自身规则处理信息，请阅读对应政策。我们不会因为您扫描到一个网址就自动访问它。

## 五、保存、安全、共享与删除

码册保存在应用私有目录，采用AES-GCM和Android Keystore保护，禁用应用自身的系统云备份；提供可选手势锁及失败尝试限制。数据保留至您主动删除、清除应用数据或卸载。卸载、清除数据或密钥失效后，本地记录可能无法恢复，手势也无远程找回服务，请提前自行备份。

接入版的SDK缓存、配置和运行标识还可能保存在本机，您可通过系统应用管理清除应用数据。该操作同时会删除本地码册及密钥，请先备份。第三方统计、广告与云控服务器处理的信息，按其处理目的、政策和适用法律要求的必要期限保存；本地清理不会自动清除服务器信息。我们不以未经核实的固定时限替代第三方实际保存规则。

除您主动打开、分享、打印、提交反馈，以及接入版本政策披露的组件通信外，本地扫码业务不向第三方提供您保存的内容。不接入SDK版不存在本节统计、广告或云控服务端处理。对于依法需要披露的信息，我们仅在适用的法律依据和必要范围内处理；未经适当告知和取得必要同意，不擅自扩大处理目的或范围。发生信息安全事件时，我们会采取补救措施，并按适用要求通知相关用户及主管部门。

## 六、您的选择与权利

您可在“码册”查阅、复制、修改备注或删除记录，在“我的”导出备份、恢复备份、关闭自动保存或清空记录。您可在系统应用权限管理中撤回相机授权，拒绝后仍能使用手动识别及其他本地功能。

您可选择不接入SDK版来使用不含第三方统计、广告或云控组件的业务功能。两个包使用相同包名和签名，互相安装属于覆盖更新，不会同时保留两个独立应用；切换前请先导出备份。若希望完全停止已安装接入版的运行，可先退出或在系统中停止该应用，再安装不接入版。

扫码业务没有需要注销的注册账号。与SDK处理、反馈信息、个人信息副本、删除、更正或撤回同意有关的其他请求，可通过第八节所列方式提出。我们会核实必要信息后依法处理，并在需要第三方协助时转交相应请求；不能将本地删除操作等同于第三方数据已被删除。

## 七、未成年人及政策变更

未成年人请在监护人指导下使用，尤其不要在二维码或反馈中填写不必要的个人信息。若监护人认为相关信息处理不适当，请联系运营方提出核查或删除请求。

本政策随实际功能及接入组件情况更新。涉及处理目的、信息种类、共享对象或用户权利的实质变化时，我们会通过应用内提示等适当方式告知，并在需要时重新取得您的同意。您可在“我的—隐私政策”查看当前正文；公开链接与本次交付两个版本内的政策正文一致。
