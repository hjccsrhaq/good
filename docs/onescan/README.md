## 一、先看您安装的是哪一版

两种安装包均可在本机扫码、制码和管理码册，无需注册账号。在“我的 → 关于应用”可查看当前版本是否接入第三方服务。

不接 SDK 版仅声明相机权限，没有互联网访问权限。扫码、制码和管理码册均在手机上完成。主动打开链接、分享或发送邮件时，由您选择的外部应用处理相应内容。

SuperCore 与友盟统计版使用第三方服务取得启动配置、展示广告和统计使用情况。联网服务可能接触设备标识、IP 地址以及广告或应用交互记录。返回桌面后，该版本仍可能联网。阅读下文后，您可以拒绝并退出，选用不接 SDK 版使用相同的本地功能。

## 二、首次打开、同意与后台运行

首次打开接入版或从旧政策版本升级时，先展示本机保存的政策。仅打开引导页、阅读正文、勾选后未继续，或点击“不同意并退出”，均不会因此启动 SuperCore 或友盟统计。只有勾选同意并点击“立即体验”或“跳过”才会保存本次选择；这里的“跳过”是跳过引导并按已勾选的选择继续。SuperCore 随后可展示自己的确认页。进入业务首页时，本应用先通知友盟用户已同意，设置采集范围，再启动统计。同意后再次打开应用会沿用这次选择。不接 SDK 版可在本地提示中选择“同意并继续”或“不同意并退出”。

退出扫码页面或切到后台时，应用释放相机。扫码业务不会在后台读取剪贴板、扫描其他应用或查询整机应用清单。扫码和制码不需要了解其他应用的安装、更新或卸载情况。接入版限制第三方组件通过本应用上下文登记这些系统事件，并移除了查找所有桌面应用的声明。为取得广告标识，接入版仅对相应设备厂商的标识服务保留定向查询。

接入版同意后，切回桌面不会自动断开所有组件的网络连接。我们在 Android 设备上观察到返回桌面后应用仍有数据收发；网络计数无法识别每一笔的内容和接收方。供应方尚未提供逐项说明，我们无法确认每次后台传输涉及哪些字段、由哪家组件发出及其频率。扫码、制码和本地码册本身无需这些后台连接。您可以在手机系统设置中强行停止应用，或选用不接 SDK 版。已经发送的信息可按第七节提出查阅或删除请求。

## 三、本地功能怎样使用您的信息

• 相机扫码。您主动点击扫码时才会申请相机权限。在本机识别二维码、条形码，预览帧不保存为照片或视频。拒绝相机权限仍可手动识别、生成二维码和使用码册。
• 码值与保存。您扫描或输入的文本、网址、电话号码、名片、Wi-Fi 名称或密码、挪车信息，以及标题、备注和收藏，可按您的操作保存在本地。单次识别可在“我的”关闭自动保存；连续扫码在完成时统一保存。扫码业务代码不向广告或统计服务提交相机画面、码值正文、码册、备注或 Wi-Fi 密码。Wi-Fi 工具只解析码内内容，不读取系统保存的密码。分享挪车码、名片码或 Wi-Fi 码时，接收方可以读到其中的信息。
• 复制与外部操作。应用响应您主动复制或粘贴的动作，复制后的内容由系统剪贴板管理。扫码得到的网址经您确认后才交给浏览器；分享或打印将选定内容交给您选择的应用或系统服务。外部接收方按其自身政策处理信息。链接格式检查、校验位计算等本地工具无需访问目标网站。
• 导入、导出和反馈。系统文件选择器只授权您选定的文件或保存位置。JSON 备份、CSV 表格、导出的码图和 PDF 可由持有文件的人读取。“问题反馈”将您填写的内容、应用版本及 Android API 版本生成本地文件；您决定是否以及向谁发送。若您联系运营者，我们使用您提供的联系方式和问题描述处理该请求。

## 六、保存、保护与对外提供

码册位于应用私有目录，使用 AES-GCM 加密，密钥由 Android Keystore 管理。可在“我的”启用本地隐私锁。本应用关闭系统自动备份。本机记录保留至您删除、清除应用数据或卸载。上述操作不会删除您已导出的文件、已分享的副本或第三方服务器上的记录。

接入版在本机还可能保存配置、缓存和运行标识。第三方统计、广告及配置服务按其披露的目的和法律要求保存服务端信息；各服务的具体期限以其官方说明及对您的答复为准。我们处理您发送的反馈和权利请求，仅保留处理及依法留存所需的最短时间。目的已实现、保存期限届满或符合其他法定删除条件时，依法删除或匿名化处理。发生个人信息安全事件时，我们将及时采取补救措施，依法履行告知和报告义务。

## 七、如何行使您的权利

• 查阅、复制、更正或删除本机内容。在“码册”选择记录，可查看、复制、修改标题或备注、删除记录；在“我的 → 备份与导出”取得副本，或使用“清除全部本地记录”。本应用无需注册，不设账号注销手续。
• 撤回权限或同意。在系统设置的本应用权限页可以关闭相机等授权。要清除本机保存的政策同意记录，可先在“我的 → 备份与导出”备份需要保留的码册，再通过系统的“应用 → 一键扫一扫二维码 → 存储 → 清除数据”操作。该操作会一并删除本地码册和设置；下次打开时会重新询问。系统菜单名称可能因机型而异。您也可以发邮件撤回同意或请求协助。撤回不影响撤回前依据同意已进行的处理。
• 停止使用统计和广告。可选用不接 SDK 版保留本地实用功能。两个安装包包名和签名相同，切换前建议先导出需要的记录。如需删除已经提交给第三方的信息，请联系运营者或相应提供方；清理手机上的数据不会替您提交这些请求。
• 提出申请或投诉。请发邮件至 hanbing@yeyukj.com，可要求解释处理规则、查阅、复制、更正、补充、删除信息，或限制、拒绝相关处理。请注明应用名称、安装版本及希望处理的事项。我们仅在办理所必要的范围内核验身份，在收到请求后十五个工作日内受理、处理并答复；如不能满足请求，将说明原因。请勿发送手机密码、完整身份证号码或含私人内容的二维码。如对处理结果有异议，您可以向有关监管部门投诉或依法提起诉讼。
